    01-B / AUTOMATION

    DOI로 초록 수집 → AI 코딩 제안 → 사람이 확정

    AI는 제안만 합니다. 사람이 확인하고 확정한 문헌만 매트릭스에 들어갑니다.

    샘플 모드

    실존 문헌 6편에 대한 AI 제안 견본을 불러옵니다. 네트워크와 API 키가 없어도 됩니다. 견본은 실제 API 호출 결과가 아니며, 사람 코딩과 다른 제안 2건을 고쳐 확정하는 연습에 씁니다.

    초록 수집은 공개 API(OpenAlex · Crossref)를 써서 키 없이 됩니다. 최대 30편.

    예상 비용은 DOI를 넣으면 표시됩니다.

    키는 각자 본인 것을 이 화면에만 넣습니다. 저장소·CSV·보고서에는 남지 않고, 이 브라우저에서 Anthropic API로만 전송됩니다. 공용 PC·화면 녹화·화면 공유 중에는 넣지 마세요. 호출 비용은 키 주인의 계정에 청구됩니다.
